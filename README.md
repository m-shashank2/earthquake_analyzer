# Earthquake Analyzer 🌍

A real-time earthquake tracking and visualization web application that fetches live seismic activity data from the USGS Earthquake API and displays it using interactive charts, maps, heatmaps, and alert systems.

---

## Features

- Live earthquake data from USGS API
- Interactive world map using Leaflet.js
- Earthquake heatmap visualization
- Sort earthquakes by:
  - Magnitude
  - Time
  - Depth
- Real-time earthquake risk alerts
- User region-based earthquake notifications
- Dark/Light theme toggle
- Responsive UI using Bootstrap
- Dynamic charts using Chart.js
